# Frontend provenance

This Vue 3/Vite client is adapted from the public DOVideo-AI client at
https://github.com/Xiaoc7r/DOVideo-AI.

The upstream project is MIT-licensed. Preserve the upstream copyright and
license notice when redistributing this client or future adaptations.

R1 adapts only the development proxy target and keeps the original public
route names, envelope handling, resumable-upload protocol, and SSE stream
consumer.
