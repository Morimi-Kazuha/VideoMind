# Repository baseline and provenance

This Git history begins from the current DOVideo Python reconstruction
snapshot established immediately before the X3 measured benchmark phase.

Earlier R4, P1–P5, X1, X2, J1, X3-A, and X3-B work predates this repository
history. Those phases are documented by existing project reports and
regression records rather than historical Git commits.

The upstream/reference project is
<https://github.com/Xiaoc7r/DOVideo-AI>. It is not this repository's Git
ancestry.
